# Revisiones del catálogo

Cada archivo de aquí es la **hoja de respuestas** de una revisión del catálogo (`docs/revision-del-catalogo.md`), tal como
la lee `publicar-cli.ts`. Es la constancia de **quién aprobó qué y cuándo**: la migración de publicación sale de ella, y
una prueba comprueba que coincide línea por línea (`PublicarElCatalogoRevisado.integracion.spec.ts`).

| Hoja                                | Migración                                      | Quién y cómo                                                                                                                                                                                                                         |
| ----------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `2026-10-20-samuel-villa-perez.txt` | `20261024120000_publicar_el_catalogo_revisado` | Samuel Villa Pérez, Scrum Master: lectura y aprobación del equipo de las 18 mecánicas pendientes y las 6 sesiones del piloto. **No es una revisión profesional** (psicología o fisioterapia), y así queda escrito en `revisada_por`. |

Una sesión revisada ya no se edita (disparador de la base). Si más adelante llega una revisión profesional, se hace sobre
sesiones nuevas.
